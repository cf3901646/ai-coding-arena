THE LONG VIEW · 1891—2026

伟大的公司，
总在重新发明自己。

飞利浦从不只属于某一种产品。灯泡、收音机、电视、磁带与 CD 曾改变一代人的生活； 如今，同样的材料科学、成像、传感、设计与数字能力，汇聚成更专注的健康科技。

拖动时间轴探索→

1891

让夜晚亮起来

Gerard Philips 在埃因霍温生产第一批可靠的白炽灯泡。光延长了人们工作、学习与生活的时间。

1924

光，第一次穿透人体

Metalix X 射线管显著减少有害辐射。飞利浦从照明跨入医学影像，技术开始服务于诊断。

1930

把筛查带给一座城市

面对结核病暴发，飞利浦先为员工、再为家庭与埃因霍温市民提供 X 光筛查，让医疗创新走向大众。

1951

看见身体的层次

Polytome 多层摄影系统成为 CT 的先声。此后的数十年，飞利浦持续推进超声、CT 与 MRI。

1963

声音进入口袋

紧凑型盒式磁带让录音与分享变得大众化。一家照明公司，逐渐塑造全球电子生活。

1982

世界开始数字聆听

飞利浦与索尼共同推动 CD 商用。光学与数字存储的积累，也加速医学影像与患者信息数字化。

2003

技术开始理解情绪

Ambient Experience 将设计、灯光与医疗技术结合，缓解 MRI 等检查中的焦虑，重新定义患者体验。

2017

影像成为手术的导航

Azurion 将影像、患者数据与三维可视化带进介入治疗室，帮助医生更精准、更高效地完成复杂治疗。

2025

用光在体内导航

LumiGuide 以光纤技术实时呈现导丝与导管的三维位置，减少对 X 射线的依赖——回到光，也超越光。

THE PIVOT · 2010s—TODAY

不是离开过去，
而是提炼过去。

过去十余年，飞利浦剥离照明与家用电器等业务，把资源集中到健康科技。 这并非一次简单的业务收缩，而是一条更清晰的选择：围绕患者、消费者与医护人员， 打通从健康生活、早期诊断，到精准治疗与居家关护的全链路。
