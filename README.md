# AI Coding Arena — 四款 AI 编程助手横向评测

用**同一条指令、同一个场景**，分别交给 **Antigravity**、**Codex**、**Kiro**、**GitHub Copilot** 四款 AI 编程助手独立实现，然后把生成结果原样嵌进同一个页面里**直接可玩、可对比**，帮助团队与管理层直观判断该选用哪款 AI 工具。

🔗 **在线体验**：<https://cf3901646.github.io/ai-coding-arena/>

纯静态网站，无需后端，所有 Demo 均可在浏览器里直接运行。

## 设计

站点采用亮色「暖羊皮纸」视觉体系，design token 参考 [cursor.com](https://cursor.com)：

| Token | 值 |
|---|---|
| 页面底色 | `#f7f7f4` |
| 前景文字 | `#26251e` |
| 卡片表面 | `#f2f1ed` |
| 强调色 | `#f54e00` |
| 边框 | 由前景色按 2.5% / 5% / 10% 透明度派生 |
| 字体 | Inter（正文）· EB Garamond（编辑体强调）· JetBrains Mono（数字与标签） |

层次靠 ~5% 递增的表面色阶和 1px 发丝线建立，几乎不使用阴影。表格无竖线、数字等宽右对齐、冠军行以橙色左边条标记。

## 场景一：简单赛车游戏 — 评测结论

| 排名 | AI | 厂商 | 综合总分 | 耗时 | 一句话点评 |
|---|---|---|---|---|---|
| 1 | **Kiro** | AWS | **51 / 60** | 35 分钟 | 玩法和操作指示明确，画面细节丰富，操控流畅无明显 bug |
| 2 | **GitHub Copilot** | GitHub | 36 / 60 | 15 分钟 | 操控流畅、无明显 bug，但缺乏具体玩法设计 |
| 3 | **Antigravity** | Google | 27 / 60 | 1 分钟 | 3D 画面花哨，但没有具体玩法，操控有 bug；出图最快 |
| 4 | **Codex** | OpenAI | 19 / 60 | 15 分钟 | 画面简陋，没有具体玩法或指示，操控有 bug |

> 结论：四个模型都能在一次对话内产出可运行的单文件 HTML，差距不在「能不能跑」，而在「是不是一个成品」。
> 对交付质量敏感的场景推荐 Kiro；对迭代速度敏感的日常编码推荐 GitHub Copilot。

完整的分维度数据和雷达图见网站首页与 [赛车游戏详情页](scenarios/racing-game.html)。

## 评分维度说明

每项 0–10 分，由同一名评估者在相同环境下人工体验后给出，避免跨人标准漂移。

| 维度 | 说明 |
|---|---|
| 功能完整度 | 是否真的做出了一个能玩／能用的完整产物 |
| 代码质量 | 结构、可读性、可维护性，是否便于二次开发 |
| 视觉/UI设计 | 画面表现力与界面细节打磨程度 |
| 性能/流畅度 | 运行帧率、响应速度、有无卡顿与崩溃 |
| 一次成型度 | 首次输出即可用的程度，需要多少次返工 |
| 指令还原度 | 是否准确理解并实现了需求本意 |

## 维护说明（给后续更新的人）

1. 把新场景 / 新 AI 的代码放进 `demos/<ai-id>/<scenario-id>/index.html`
2. 打开 `assets/js/scores-data.js` 填分数、耗时、点评、`pros` / `cons` 标签
3. 保存后首页雷达图、排名表、场景对比页会**自动同步**，无需改动任何 HTML
   （某个场景的分数全为 0 时，该场景页会自动显示「评测进行中」空状态）

> 提示：如果某个 Demo 依赖外部 CDN（例如 Antigravity 版本依赖 Three.js CDN），需要联网才能看到完整效果，已在对应卡片的说明中注明。
