# AI Coding Arena — AI 编程助手横向评测

用**同一条指令、同一个场景**，分别交给多款 AI 编程助手独立实现，然后把生成结果原样嵌进同一个页面里**直接可玩、可对比**，帮助团队与管理层直观判断该选用哪款 AI 工具。

已参评 4 款：**Kiro**（AWS）、**GitHub Copilot**（GitHub）、**Antigravity**（Google）、**Codex**（OpenAI）。两个场景阵容一致，总分可直接比较。

🔗 **在线体验**：<https://cf3901646.github.io/ai-coding-arena/>

纯静态网站，无需后端，所有 Demo 均可在浏览器里直接运行。

## 设计

站点采用亮色「暖羊皮纸」视觉体系，design token 参考 [cursor.com](https://cursor.com)：

| Token | 值 |
|---|---|
| 页面底色 | `#f7f7f4` |
| 前景文字 | `#26251e` |
| 卡片表面 | `#f2f1ed` |
| 强调色 | `#f54e00` |
| 边框 | 由前景色按 2.5% / 5% / 10% 透明度派生 |
| 字体 | Inter（正文）· EB Garamond（编辑体强调）· JetBrains Mono（数字与标签） |

层次靠 ~5% 递增的表面色阶和 1px 发丝线建立，几乎不使用阴影。表格无竖线、数字等宽右对齐、冠军行以橙色左边条标记。

## 综合排名（截至 2 / 3 场景）

| 排名 | AI | 赛车游戏 | 编年史 | 总分 | 得分率 | 累计耗时 |
|---|---|---|---|---|---|---|
| 1 | **Kiro** | 51 / 60 | **54 / 60** | **105 / 120** | **88%** | 68.5 分钟 |
| 2 | **GitHub Copilot** | 36 / 60 | 49 / 60 | 85 / 120 | 71% | 21 分钟 |
| 3 | **Antigravity** | 27 / 60 | 42 / 60 | 69 / 120 | 57% | **2 分钟** |

> **时间性价比**：Antigravity 用 2 分钟拿到 57%，是 Kiro（68.5 分钟拿 88%）的 1/34 时间成本；

> Codex 花了 30 分钟却只有 48%，四者中投入产出比最低。

## 场景一：简单赛车游戏 — 评测结论

| 排名 | AI | 厂商 | 综合总分 | 耗时 | 一句话点评 |
|---|---|---|---|---|---|
| 1 | **Kiro** | AWS | **51 / 60** | 35 分钟 | 玩法和操作指示明确，画面细节丰富，操控流畅无明显 bug |
| 2 | **GitHub Copilot** | GitHub | 36 / 60 | 15 分钟 | 操控流畅、无明显 bug，但缺乏具体玩法设计 |
| 3 | **Antigravity** | Google | 27 / 60 | 1 分钟 | 3D 画面花哨，但没有具体玩法，操控有 bug；出图最快 |
| 4 | **Codex** | OpenAI | 19 / 60 | 15 分钟 | 画面简陋，没有具体玩法或指示，操控有 bug |

> 结论：四个模型都能在一次对话内产出可运行的单文件 HTML，差距不在「能不能跑」，而在「是不是一个成品」。
> 对交付质量敏感的场景推荐 Kiro；对迭代速度敏感的日常编码推荐 GitHub Copilot。

完整的分维度数据和雷达图见网站首页与 [赛车游戏详情页](scenarios/racing-game.html)。

## 场景二：飞利浦编年史页面 — 评测结论

**提示词**：给飞利浦这家公司设计一个简单的编年史 HTML 页面，简单诉说飞利浦公司的历史，重点且详细展示当前公司的转型和业务，以及公司产品、未来愿景等内容。具体怎么做你自己决定，但要高级流畅，展现大公司的历史和对人类的贡献。

| 排名 | AI | 综合总分 | 耗时 | 一句话点评 |
|---|---|---|---|---|
| 1 | **Kiro** | **54 / 60** | 33.5 分钟 | 叙事最完整、数据经核查最准，唯一实现无障碍降级，零渲染缺陷 |
| 2 | **GitHub Copilot** | 49 / 60 | 6 分钟 | 结构工整、32KB 零依赖加载最快、零缺陷，但视觉缺少记忆点 |
| 3 | **Antigravity** | 42 / 60 | **1 分钟** | 配色观感最舒服、唯一有可用交互，但内容最薄且手机/平板均横向溢出 |
| 4 | **Codex** | 39 / 60 | 15 分钟 | **画面最好看**、唯一用真实实拍图，却带两处渲染缺陷、内容最少 |

评测结合两类依据：**客观实测**用真实浏览器（Playwright + Chromium）渲染后量化测量；**主观判断**由评估者实际浏览后给出（视觉观感、叙事质量）。

| 实测项 | Codex | Antigravity | Copilot | Kiro |
|---|---|---|---|---|
| 正文中文字数 | 1428 | 2266 | 2503 | **4709** |
| 年份节点数 | 11 | 7 | 17 | **36** |
| 数值断言数 | 35 | 3 | 33 | **95** |
| 真实配图 | **6 张** | 0 | 0 | 0 |
| 加载耗时 / 体积 | 254ms / 844KB | 654ms / 132KB | **163ms / 32KB** | 522ms / 80KB |
| 滚动帧率 | 61fps | 61fps | 60fps | 60fps |
| 移动端 390px 溢出 | 无 | **26px** | 无 | 无 |
| 平板 768px 溢出 | 无 | **26px** | 无 | 无 |
| 中文标题行高塌陷 | **2 处** | 无 | 无 | 无 |
| 减少动效模式降级 | ✅ | ❌ | ❌ | **✅** |
| 锚点导航死链 | 0 | 0 | 0 | 0 |
| JS 报错 | 0 | 0 | 0 | 0 |

**三个关键发现：**

1. **Codex 的产物混进了终端输出。** HTML 第 10–12 行出现了 `Exit code: 0` / `Wall time: 0.3 seconds` / `Output:`。CSS 解析器在顶层遇到 `Exit` 会把它当选择器起始，一路吞到下一个 `{`，导致紧随其后的整个 `:root` 变量块失效——7 个颜色变量全部为空。A/B 实验证实：删掉这 46 个字符后变量全部复活。属于「降级但不崩溃」，页面仍可读，但品牌蓝与米色底全丢。**值得注意的是：它「画面最好看」这个评价，是在配色已经失效的状态下拿到的。**

2. **数据准确性经独立核查。** Kiro 的 €17.8B 营收、可比增长 2%、**Q4 单季 +7%** 与官方财报一致，BlueSeal / Azurion / Zenition / Rembra / SmartIQ 均为真实在售产品，并附了数据来源清单；但超声平台 **「Alturion」查无此物**（真实产品线为 EPIQ / Affiniti / Lumify），属虚构，对外发布前必须修正。Copilot 的「约 7 万员工」与 2024 年报的 68,419 略有出入。

3. **Antigravity 与 Copilot 的 7 分差距，不在视觉而在完成度。** 视觉维度 Antigravity 实际高于 Copilot（8 vs 7，配色观感更好）；差距来自内容量（5 个时间轴条目 vs 17 个年份节点）、响应式 bug（手机与平板各溢出 26px）和加载性能（654ms/132KB vs 163ms/32KB）。**如果只看桌面端第一眼观感，两者确实接近。**

完整数据见 [编年史详情页](scenarios/philips-chronicle.html)。

## 评分维度说明

每项 0–10 分。赛车游戏场景由评估者人工体验后给分；编年史场景改用真实浏览器量化测量（内容密度、渲染缺陷、无障碍、响应式、性能）并对财务与产品数据做独立事实核查，减少主观漂移。

| 维度 | 说明 |
|---|---|
| 功能完整度 | 是否真的做出了一个能玩／能用的完整产物 |
| 代码质量 | 结构、可读性、可维护性，是否便于二次开发 |
| 视觉/UI设计 | 画面表现力与界面细节打磨程度 |
| 性能/流畅度 | 运行帧率、响应速度、有无卡顿与崩溃 |
| 一次成型度 | 首次输出即可用的程度，需要多少次返工 |
| 指令还原度 | 是否准确理解并实现了需求本意 |

## 维护说明（给后续更新的人）

1. 把新场景 / 新 AI 的代码放进 `demos/<ai-id>/<scenario-id>/index.html`
2. 打开 `assets/js/scores-data.js` 填分数、耗时、点评、`pros` / `cons` 标签
3. 保存后首页雷达图、排名表、场景对比页会**自动同步**，无需改动任何 HTML
   （某个场景的分数全为 0 时，该场景页会自动显示「评测进行中」空状态）

> 提示：如果某个 Demo 依赖外部 CDN（例如 Antigravity 版本依赖 Three.js CDN），需要联网才能看到完整效果，已在对应卡片的说明中注明。
