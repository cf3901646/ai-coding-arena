# 🏁 AI Coding Arena — 4款AI编程助手横向评测

用**同一个需求、同一个场景**，分别交给 **Antigravity**、**Codex**、**Kiro**、**GitHub Copilot** 四款 AI 编程助手去实现，然后把生成结果放在同一个页面里**直接可玩、可对比**，帮助团队/管理层直观判断该选用哪款 AI 工具。

🔗 **在线体验**：`https://cf3901646.github.io/ai-coding-arena/` （启用 GitHub Pages 后即可访问）

纯静态网站，无需后端，所有 Demo 均可在浏览器里直接运行。

## 场景一：简单赛车游戏 — 评测结论

| 排名 | AI | 综合总分 | 一句话点评 |
|---|---|---|---|
| 🥇 | **Kiro** | 51 / 60 | 玩法和操作指示明确，画面细节丰富，操控流畅无明显bug（耗时35分钟，最长） |

## 目录结构
```
├── index.html                  # 总览首页：结论摘要 + 综合雷达图 + 分维度得分排行表
├── scenarios/                  # 三个场景详情页（每页并排展示4个AI的可玩Demo）
│   ├── racing-game.html
│   ├── philips-chronicle.html
│   └── dashboard.html
├── demos/                      # 4个AI × 3个场景 的实际产出代码
│   ├── antigravity/{racing-game, philips-chronicle, dashboard}/
│   ├── codex/...
│   ├── kiro/...
│   └── copilot/...
└── assets/
    ├── css/style.css
    └── js/
        ├── scores-data.js      # ★ 唯一的数据源：AI名称/打分/点评，改这里全站自动同步
        ├── main.js             # 首页渲染逻辑（雷达图 + 按总分自动排名的表格）
        └── scenario.js         # 场景页渲染逻辑
```

## 评分维度说明
| 维度 | 说明 |
|---|---|
| 功能完整度 | 是否覆盖了需求的核心功能，有没有明显缺失/报错 |
| 代码质量 | 结构清晰度、可读性、命名规范、是否有明显冗余 |
| 视觉/UI设计 | 界面美观度、排版、配色、交互细节 |
| 性能/流畅度 | 加载速度、动画/游戏帧率、大数据量下的响应速度 |
| 一次成型度 | 是否基本不需要人工二次修改即可使用 |
| 指令还原度 | 是否准确理解并落实了原始需求 |

## 本地预览
```powershell
python -m http.server 8080
```
浏览器打开 `http://localhost:8080`

## 维护说明（给后续更新的人）
1. 把新场景/新AI的代码放进 `demos/<ai-id>/<scenario-id>/index.html`
2. 打开 `assets/js/scores-data.js` 填分数、耗时、点评
3. 保存后首页雷达图、排名表、场景对比页会**自动同步**，无需改动任何 HTML

> 提示：如果某个 Demo 依赖外部 CDN（例如 Antigravity 版本依赖 Three.js CDN），需要联网才能看到完整效果，已在对应卡片的说明中注明。
